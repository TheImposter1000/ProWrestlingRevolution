DATABASES
Each wrestling universe lives in its own folder under Databases.
Use the DATABASE SELECTOR on the main menu to import a Microsoft Access .mdb file.
For example: Databases/Default/PWR.mdb
New careers are copied into Databases/Default/SaveGames/<Career>/PWRSave.mdb
Each career includes Backups/initial.mdb.
The application never silently overwrites the original universe.
A custom-created MDB may not share the schema of future Pro Wrestling Revolution gameplay systems.
No third-party protected databases are bundled with the game.
